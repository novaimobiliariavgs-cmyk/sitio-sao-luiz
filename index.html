Como guardar os dados

Os dados ficam salvos neste navegador, neste computador. Se limpar o histórico/cache do navegador ou abrir em outro aparelho, eles não aparecem. Por isso, use Exportar planilha com frequência e guarde o arquivo (pasta, pendrive, Google Drive). Para recuperar ou levar para outro computador, use Importar planilha com o último arquivo exportado.
